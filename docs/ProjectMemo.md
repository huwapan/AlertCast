# プロジェクトメモ

## スケジュールの種類

日時は `YYYY-MM-DD HH:MM:SS`、日付は `YYYY-MM-DD` 形式で保存する。
日本の時間でタームゾーンを設定する
作成日時（created_at）・更新日時（updated_at）も日本時間で、かならずプログラムから入れる（列の初期値 CURRENT_TIMESTAMP は世界標準時になるため使わない）

### 時間内で終わる予定
- 必須項目：タイトル、開始日時、終了日時、優先度
- 開始日時と終了日時を持つ。

### 一日単位の予定
- 日付ごとに管理し、時間指定の予定とは別に編集できるようにする。
- 1件の予定は1日分とし、別の日にも登録する場合は日付ごとに管理する。

### 期限で終わらせる予定
- 必須項目：タイトル、開始日、終了日
- 優先度は任意。

## 予定の状態とホームでの表示

時間指定予定は、終了日時と完了したかどうかで、ホームの次の場所に表示する（削除済みの予定はどこにも出さない）。

- 今日の予定：開始から終了までの間に今日がかかる予定。完了済みの予定も「完了」と表示して出す。
- 完了通知：終了日時を過ぎてから1日（24時間）以内で、まだ完了していない予定。「完了」ボタンで完了にする。
- 期限を超過した予定：終了日時から1日（24時間）以上3日（72時間）未満で、完了していない予定。ここでも「完了」ボタンで完了にできる。
- 長く放置されている予定：終了日時から3日（72時間）たっても完了していない予定。「完了」ボタンのほか、変更フォームと削除フォームへのリンクを出す。
