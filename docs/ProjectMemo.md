# プロジェクトメモ

## スケジュールの種類

日時は `YYYY-MM-DD HH:MM:SS`、日付は `YYYY-MM-DD` 形式で保存する。
日本の時間でタームゾーンを設定する

### 時間内で終わる予定
- 必須項目：タイトル、開始日時、終了日時、優先度
- 開始日時と終了日時を持つ。

### 一日単位の予定
- 日付ごとに管理し、時間指定の予定とは別に編集できるようにする。
- 1件の予定は1日分とし、別の日にも登録する場合は日付ごとに管理する。

### 期限で終わらせる予定
- 必須項目：タイトル、開始日、終了日
- 優先度は任意。

## 今後決めること
- 優先度の値と表示方法
- 日常的な予定とイベント的に発生した予定の分類方法
- 繰り返し予定の扱い（スケジュール案を作る場合は日常的な予定を対象にする）
