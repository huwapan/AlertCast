- 提案
    - 予定を提案する
        - v [ ] 普段の生活から予定（スケジュール）を提案する
            - [ ] 興味があるカテゴリーを設定する
                - ^ [ ] 興味があるカテゴリーのイベント情報をお知らせする
- 入力
    - 予定を入力する
        - [ ] 文字で入力
            - ^ [ ] 期限を入力
                - [ ] 優先度を入力
- 調整
    - 予定を調整してくれる
        - v [ ] 優先度をつけて予定（スケジュール）を確認する
            - [ ] 普段の生活からおすすめのスケジュール案を提出する
- 変更
    - 予定を変更する
        - [ ] 既に入力されている予定を変更する
            - [ ] 優先度をつけて予定（スケジュール）を作り直す
- 想起
    - 予定を思い出す
        - [ ] 今日の予定を教える
            - ^ [ ] 忘れて期限を超過している予定を教える
                - ^ [ ] 長く放置されている予定を教える
                    - [ ] TODOリストを教える
                        - ^ [ ] 完了した予定の振り返り表を送る
- 確認
    - 予定完了を確認する
        - [ ] 予定完了を通知を出してボタン操作で確認する
- 削除
    - 予定を取り消す
        - [ ] 予定を削除する
- 改善
    - 予定を改善する
        - v [ ] 予定立てのフィードバックを受けて改善する
